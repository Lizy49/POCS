
| Поле                            | Описание                                                                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор и название        | UC-2 Учет багажа в аэропорту                                                                                                                                                    |
| Основное действующее лицо       | Сотрудник багажного отдела                                                                                                                                                      |
| Описание                        | Оператор принимает багаж пассажира, проверяет его параметры, оформляет и отправляет в систему хранения и погрузки.                                                              |
| Триггер                         | Пассажир обращается для сдачи багажа                                                                                                                                            |
| Предварительные условия         | PRE-1. Оператор авторизован в системе PRE-2. У пассажира есть билет PRE-3. Рейс существует в системе                                                                            |
| Выходные условия                | POST-1. Багаж зарегистрирован POST-2. Данные сохранены в системе                                                                                                                |
| Нормальное направление развития | 1. Оператор выбирает рейс 2. Проверяет билет пассажира 3. Вводит данные багажа 4. Система проверяет вес и размеры 5. Система сохраняет данные 6. Багаж отправляется на погрузку |
| Альтернативное направление      | 1. Вес багажа превышает норму 2. Система рассчитывает доплату 3. Пассажир оплачивает превышение                                                                                 |
| Исключение                      | Е1. Багаж превышает допустимые размеры -> система запрещает оформление Е2. Рейс закрыт -> оформление невозможно                                                                 |
| Бизнес-правила                  | BR-1. Один пассажир может оформить багаж только на свой рейс BR-2. Вес багажа не должен превышать установленные нормы                                                           |
| Частота использования           | Постоянно в рабочее время аэропорта                                                                                                                                             |
**UC-3 Посадка на рейс**

| Поле                            | Описание                                                                                                                                                                               |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Идентификатор и название        | UC-3 Посадка на рейс<br>                                                                                                                                                               |
| Основное действующее лицо       | Оператор посадки                                                                                                                                                                       |
| Описание                        | Оператор выполняет проверку пассажира перед посадкой и подтверждает допуск на рейс                                                                                                     |
| Триггер                         | Пассажир предъявляет посадочный талон перед выходом на посадку                                                                                                                         |
| Предварительные условия         | PRE-1. Пассажир зарегистрирован на рейс PRE-2. Посадочный талон выдан PRE-3. Рейс доступен для посадки                                                                                 |
| Выходные условия                | POST-1. Посадка пассажира подтверждена PRE-2. Данные о посадке сохранены в системе                                                                                                     |
| Нормальное направление развития | 1. Оператор сканирует посадочный талон 2. Система проверяет регистрацию пассажира 3. Система проверяет статус рейса 4. Оператор подтверждает посадку 5. Система фиксирует факт посадки |
| Альтернативное направление      | 1. Пассажир меняет место перед посадкой 2. Система обновляет данные посадки                                                                                                            |
| Исключение                      | Е1. Пассажир не зарегистрирован -> посадка запрещена Е2. Посадка на рейс завершена Е3. Посадочный талон недействителен                                                                 |
| Бизнес-правила                  | BR-1. Посадка разрешена только зарегистрированным пассажирам BR-2. Один посадочный талон может быть использован только один раз                                                        |
| Частота использования           | Перед каждым билетом рейса                                                                                                                                                             |
